# Rudransh Megamart Store – Power BI Sales Dashboard

## 📊 Project Overview

The **Rudransh Megamart Store Sales Dashboard** is an interactive **Power BI data analytics project** designed to analyze sales, quantity, profit, products, categories, sub-categories, cities, and regions.

The dashboard provides a clear overview of business performance and helps identify important sales and profit trends using interactive visualizations and filters.

## 🎯 Project Objectives

* Analyze overall sales performance.
* Analyze total quantity sold by product.
* Understand sales performance across different sub-categories.
* Analyze profit trends by year.
* Compare business performance across different regions.
* Analyze sales based on cities and categories.
* Identify high-performing products and sub-categories.
* Create an interactive and user-friendly business dashboard.

## 📌 Dashboard Features

* **Total Sales KPI**
* **Quantity by Product Name**
* **Sales by Sub-Category**
* **Profit by Year**
* **City Filter**
* **Category Filter**
* **Region Analysis**
* **Product ID Analysis**
* Interactive Power BI visuals and slicers

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query**
* **DAX**
* **Microsoft Excel / Dataset**
* **Data Visualization**
* **Data Cleaning & Transformation**

## 📈 Key Insights

The dashboard helps users understand:

* Which products have higher quantities sold.
* Which sub-categories generate higher sales.
* How profit changes across different years.
* Which regions contribute to business performance.
* How product and category selections affect overall results.

## 🔄 Project Workflow

1. Import the dataset into Power BI.
2. Clean and transform data using Power Query.
3. Change and validate data types.
4. Create relationships between tables where required.
5. Create DAX measures for sales, quantity, and profit analysis.
6. Design interactive charts and KPI visuals.
7. Add slicers for City and Category.
8. Build the final interactive dashboard.
9. Analyze business insights from the dashboard.
